🎭 사용법 / 단축키

기본 조작

  • 역할 추가 → 씬 추가 → 무대에서 마커를 드래그해 위치, 손잡이로 방향 지정
  • 역할 클릭 = 강조 (여러 명 동시 선택 가능), 다시 클릭하면 해제
  • "전체 동선 보기"로 강조한 역할들의 전체 씬 이동 경로 확인 (퇴장 구간은 선으로 잇지 않고 끊어서 표시)
  • 씬 복제로 비슷한 포메이션을 빠르게 이어서 만들기
  • 역할 목록의 "등장/퇴장" 버튼으로 그 역할이 현재 씬에 있는지 없는지 표시 — 퇴장 상태면 무대에 마커가 보이지 않음. 다시 등장시키면 마지막 위치에서 다시 나타나며, 그대로 드래그해서 새 위치로 옮기면 됩니다
  • 역할을 2명 이상 선택하면 나타나는 정렬 도구로 가로/세로 줄맞춤, 균등 간격 배치, 무대 중앙으로 한 번에 이동 가능
  • 무대 바닥에 옅은 격자선이 있어 위치·대칭을 눈대중보다 정확히 맞출 수 있습니다
  • 실제 연습실 객석 방향이 반대이거나, 무대 좌우가 바뀌어야 한다면 "⇅ 객석 위/아래 전환" / "⇄ 무대 좌우 반전" 버튼으로 모든 씬의 위치·바라보는 방향을 한 번에 뒤집을 수 있습니다 (전체 씬 대상 대량 편집이라 확인창이 뜨며, 실행취소로만 되돌릴 수 있습니다)

음원 연동

  • 파형이 그려진 큰 탐색 막대를 클릭/드래그해서 정밀 탐색, 또는 ±1초/±0.1초 버튼과 시간 입력칸(mm:ss.s)으로 세밀하게 위치 조정
  • 원하는 지점에서 정지 → "현재 위치 → 대형 완성 큐로 저장" (탐색 막대에 주황색 눈금으로 표시됨) — 이 씬의 대형이 완성되는(도착하는) 시간
  • "현재 위치 → 이동 시작으로 저장" (탐색 막대에 색이 다른 아래쪽 깃발 눈금으로 표시됨) — 직전 대형에서 이 씬으로 움직이기 시작하는 시간. 비워두면 직전 큐 직후 바로 이동을 시작합니다
  • 이동 시작 시간을 지정하면, 재생 중 배우들은 직전 대형에서 가만히 있다가 이동 시작 시간부터 움직이기 시작해 대형 완성 큐 시간에 정확히 도착합니다 (노래 내내 계속 움직이는 문제 방지)
  • 가사는 씬(포메이션)이 아니라 노래 자체에 시간으로 붙습니다. 음원을 재생하면서 "가사 한 줄 입력" 칸에 타이핑하고 Enter(또는 "➕ 현재 위치에 추가")를 누르면, 그 순간의 재생 위치가 그 줄의 시간으로 저장됩니다
  • 듀엣/앙상블처럼 보이스가 겹칠 때는 입력칸 옆 드롭다운에서 그 줄의 파트(역할)를 지정할 수 있습니다. 역할별로 독립된 줄로 취급되어 같은 시간에 여러 역할의 줄이 동시에 강조될 수 있습니다. 이미 만든 줄은 앞의 색점/이름표를 클릭해서 파트를 바꿀 수 있습니다
  • 하단 가사 프롬프터는 유튜브 뮤직 가사처럼, 재생 위치에 맞춰 현재 줄(들)이 크고 진하게 강조되고 자동으로 스크롤됩니다. 줄을 클릭하면 그 시점으로 바로 이동, 더블클릭하면 텍스트 수정, ⏱로 시간 재조정, ✕로 삭제할 수 있습니다
  • 재생 중 무대 오른쪽 위에 "다음 이동까지 -x초" 표시가 떠서, 다음 큐까지 얼마나 남았는지 미리 확인할 수 있습니다 (다음 큐가 없으면 표시되지 않습니다)
  • 음원이 있으면 무대 바로 아래에 재생/정지 버튼과 현재 가사 한 줄을 보여주는 작은 바가 항상 붙어 있어서, 스크롤해서 아래 음원 패널까지 내려가지 않아도 무대를 보면서 재생 상태와 가사를 바로 확인할 수 있습니다

키보드 단축키 (입력창 밖에서)

  • ← / → — 이전/다음 씬
  • Space — 음원 재생/정지
  • Ctrl+Z (Mac: Cmd+Z) — 실행 취소 (역할/씬 추가·삭제, 위치·방향 이동)
  • Esc — 이 도움말 닫기

배포

  • "배포용 HTML로 내보내기"를 누르면, 지금까지의 동선·음원·가사가 그대로 담긴 파일 하나가 만들어집니다. 연출진/배우에게 이 파일만 전달하면 됩니다. 내보낸 파일은 항상 편집 모드가 꺼진 "보기 모드"로 열려서, 실수로 위치를 바꿀 걱정 없이 바로 확인할 수 있습니다.
  • 편집 모드를 끄면(보기 모드) JSON 저장/불러오기, 배포용 HTML 내보내기, 실행취소, 역할·씬 추가/삭제 등 편집용 버튼이 모두 숨겨지고, 역할을 탭해서 강조하는 등 확인용 기능만 남습니다. 헤더의 "최종 수정" 표시로 마지막으로 편집된 시각을 알 수 있습니다.
  • 보기 모드로 처음 열면 화면 위에 짧은 안내 배너("처음이신가요?...")가 한 번 뜨고, ✕로 닫으면 그 기기에서는 다시 뜨지 않습니다.
  • 아이폰에서 화면은 뜨는데 아무 반응이 없다면: 카카오톡 등에서 파일을 바로 탭하면 iOS가 자바스크립트가 실행되지 않는 "미리보기" 화면으로 엽니다. 공유 버튼 → "다른 앱으로 열기" → Safari를 선택해야 정상 동작합니다. 이 경우 화면 맨 위에 빨간 안내 문구가 자동으로 뜹니다.
  • 파일 앱에 저장 후 Safari/Chrome으로 직접 열었는데도 반응이 없다면, 화면 위쪽에 보라색 오류 문구가 뜨는지 확인해주세요. 뜬다면 그 문구를 그대로 스크린샷해서 보내주시면 정확한 원인을 바로 찾을 수 있습니다.
