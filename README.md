# 뮤지컬 동선 확인용 MVP

정적 HTML 한 장으로 된 편집 가능한 동선(블로킹) 확인 툴입니다. 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 사용 흐름

1. `index.html`을 더블클릭해서 브라우저(Chrome 등)로 엽니다.
2. 왼쪽 패널에서 **역할**을 이름으로 추가합니다 (예: 왕비, 기사1, 시녀2 ...).
3. 오른쪽 패널에서 **씬(장면)**을 하나씩 추가합니다. 새 씬은 직전 씬의 위치를 그대로 이어받으므로, 실제로 움직인 역할만 무대에서 드래그로 옮기면 됩니다.
4. 씬 이름과 메모(예: "여기서 기사1 퇴장")를 입력해 두면 나중에 알아보기 쉽습니다.
5. 이 과정을 씬 개수만큼 반복하면 전체 동선표가 완성됩니다.

## 확인용 기능

- **역할 클릭 → 강조 (다중 선택 가능)**: 왼쪽 목록에서 역할을 클릭하면 강조 목록에 추가되어 밝게, 나머지는 흐리게 표시됩니다. 여러 역할을 동시에 클릭해 그룹으로 강조할 수 있고, "전체 해제"로 한 번에 풀 수 있습니다.
- **전체 동선 보기**: 강조한 역할들이 모든 씬에서 어디서 어디로 이동하는지 각자 자기 색상의 점선 경로 + 씬 번호로 표시됩니다. 퇴장한 구간은 선으로 잇지 않고 끊어서 보여줍니다.
- **정렬 도구 (역할 2명 이상 선택 시 표시)**: 역할을 여러 명 선택하면 "선택한 역할 정렬" 도구가 나타납니다. **가로 정렬**은 선택한 역할들을 같은 높이(Y)로 맞추고, **세로 정렬**은 같은 좌우 위치(X)로 맞춥니다. **균등 간격**은 선택한 역할들을 가로 방향으로 같은 간격이 되도록 자동으로 배치합니다(일렬로 세울 때 유용). **무대 중앙으로**는 선택한 역할(1명부터 가능)을 무대 정중앙 세로선으로 이동시킵니다. 모두 편집 모드에서, 현재 보고 있는 씬에만 적용됩니다.
- **등장/퇴장 (씬별 출연 여부)**: 역할 목록 각 항목의 "등장/퇴장" 버튼으로, 그 역할이 지금 보고 있는 씬에 있는지 없는지를 표시할 수 있습니다. "퇴장"으로 표시하면 그 씬에서는 무대에 마커가 아예 나타나지 않습니다. 다시 "등장"으로 돌리면 마지막으로 있던 위치에서 나타나므로, 그대로 드래그해서 새로 등장하는 위치로 옮기면 됩니다. 씬을 추가하면 직전 씬의 등장/퇴장 상태도 그대로 이어받습니다. 무대 아래에는 현재 씬에서 퇴장 중인 역할 이름이 표시됩니다.
- **바라보는 방향**: 각 마커에 붙은 작은 원(손잡이)을 드래그하면 그 역할이 바라보는 방향이 바뀝니다. 씬마다 따로 저장됩니다.
- **무대 바닥 격자**: 위치·대칭을 눈대중보다 정확히 맞출 수 있도록 무대 바닥에 옅은 격자선이 표시됩니다.
- **객석/좌우 반전 (전체 씬 대상)**: 실제 연습실의 객석 방향이 반대이거나 무대 좌우가 바뀌어야 할 때, "⇅ 객석 위/아래 전환" / "⇄ 무대 좌우 반전" 버튼으로 모든 씬의 위치와 바라보는 방향을 한 번에 뒤집을 수 있습니다. 특정 씬 하나만이 아니라 전체 씬을 건드리는 대량 편집이라 확인 창이 한 번 뜨고, 마음에 안 들면 실행취소(Ctrl+Z)로만 되돌릴 수 있습니다.
- **이전/다음 씬, 씬 자동재생, 씬 복제**: 버튼으로 씬을 넘기면 마커가 부드럽게 이동해서 동선 흐름을 파악할 수 있습니다. "씬 자동재생"은 음원과 무관하게 씬을 순서대로 넘기는 기능이고, "씬 복제"는 비슷한 포메이션을 빠르게 이어 만들 때 씁니다.
- **편집 모드 끄기 (보기 모드)**: 상단의 "편집 모드" 체크를 끄면 JSON 저장/불러오기, 배포용 HTML 내보내기, 실행취소, 역할·씬 추가/삭제/정렬 등 편집용 버튼과 조작이 모두 숨겨지고, 역할을 탭해서 강조하는 등 확인에 필요한 기능만 남습니다. 배우들에게 나눠줄 때 실수로 위치가 바뀌지 않게 하는 용도입니다. 헤더에는 마지막으로 편집한 시각이 "최종 수정 MM/DD HH:MM"으로 표시됩니다. 보기 모드로 처음 열리면 짧은 안내 배너가 한 번 뜨고, 닫으면 그 기기에서는 다시 뜨지 않습니다.
- **실행 취소**: 상단 "⎌ 실행취소" 버튼 또는 `Ctrl+Z`(Mac: `Cmd+Z`)로 역할/씬 추가·삭제, 위치·방향 변경을 되돌릴 수 있습니다.
- **자동 백업**: 이 폴더는 git 저장소가 아니라 실행취소 말고는 되돌릴 수단이 마땅치 않아서, 편집할 때마다 브라우저에 몇 분 간격으로 자동 백업이 쌓입니다(최근 6개, 음원 파일 제외). 헤더의 "🕐 백업" 버튼으로 이전 시점 목록을 보고 "이 시점으로 복구"할 수 있습니다. 복구도 실행취소로 다시 되돌릴 수 있어요.
- **다크 모드**: 헤더의 🌙/☀️ 버튼으로 어두운 연습실에서도 보기 편한 다크 테마로 전환할 수 있습니다.
- **도움말**: 헤더의 ❓ 버튼을 누르면 조작법과 단축키를 요약해서 보여줍니다.
- **키보드 단축키** (입력창 밖에서): `←`/`→` 이전/다음 씬, `Space` 음원 재생/정지, `Ctrl+Z` 실행 취소.

## 음원 연동 & 가사 프롬프터

1. 하단 "음원 & 대사/가사 타임라인" 패널에서 **음원 업로드**로 mp3 등 오디오 파일을 올립니다. 업로드하면 파형(웨이브폼)이 그려진 큰 탐색 막대가 나타납니다.
2. **정밀 탐색**: 파형 막대를 클릭하거나 드래그해서 원하는 지점으로 이동할 수 있고, 그 아래 `⏮ 1s` / `◀ .1s` / `▶ 재생` / `.1s ▶` / `1s ⏭` 버튼으로 1초, 0.1초 단위까지 세밀하게 조정할 수 있습니다. 시간 입력칸(`mm:ss.s`)에 정확한 시간을 직접 타이핑해서 그 위치로 바로 이동할 수도 있습니다. 오른쪽의 🔊 슬라이더로 볼륨도 조절됩니다.
3. 씬 편집 영역(무대 위쪽)에서 **"이 대형 완성 시간(큐)"**을 지정해 동선을 음원에 맞춥니다. (아래 가사는 이제 씬이 아니라 노래 자체에 시간으로 붙습니다 — 별개입니다.)
4. **가사는 노래를 들으면서 실시간으로 입력합니다.** 음원을 재생한 채로 하단 "가사 한 줄 입력" 칸에 지금 나오는 가사를 타이핑하고 `Enter`(또는 "➕ 현재 위치에 추가")를 누르면, 그 순간의 재생 위치가 그 줄의 시간으로 자동 저장됩니다. 다음 줄이 나올 때 같은 방식으로 계속 입력하면 노래 전체의 가사가 시간 순으로 쌓입니다.
5. **듀엣/앙상블처럼 여러 보이스가 겹칠 때**: 입력칸 왼쪽의 파트 선택(드롭다운)에서 이 줄이 어느 역할의 파트인지 고를 수 있습니다(선택하지 않으면 "공통"). 각 역할은 독립적인 줄로 취급되어서, 같은 시간대에 서로 다른 역할의 줄이 동시에 활성화될 수 있습니다 — 예를 들어 역할1과 역할2가 겹쳐 부르는 구간이면 두 줄이 동시에 강조됩니다(각자 그 역할의 색으로). 이미 입력한 줄의 파트는 줄 앞의 색점/이름표를 클릭하면 다음 역할로 바뀌고, 계속 클릭하면 "파트 없음"으로 돌아옵니다.
6. 저장된 가사는 하단에 **가사 프롬프터**로 표시됩니다 — 유튜브 뮤직 가사처럼, 재생 위치에 맞춰 현재 줄(들)이 크고 진하게 강조되고 화면이 자동으로 스크롤됩니다.
7. 가사 줄을 클릭하면 음원이 그 줄의 시작 시점으로 이동합니다. 줄을 더블클릭하면 텍스트를 수정할 수 있고, 각 줄의 ⏱ 버튼으로 시간을 다시 잡거나(현재 재생 위치로 재조정) ✕ 버튼으로 삭제할 수 있습니다.
8. 씬의 "대형 완성 큐"가 설정되어 있으면 씬 사이 자동 이동도 함께 재생에 맞춰 동작하지만, 가사와는 별개의 시간 값이라 서로 영향을 주지 않습니다.
9. 재생 중에는 무대 오른쪽 위에 "다음 이동까지 -x초" 카운트다운이 떠서, 다음 큐까지 남은 시간을 미리 확인할 수 있습니다(다음 큐가 없으면 표시되지 않습니다).
10. 음원이 업로드되어 있으면 무대 바로 아래에 재생/정지 버튼과 현재 가사 한 줄을 보여주는 작은 바가 항상 붙어 있습니다. 아래쪽 음원 패널까지 스크롤하지 않아도 무대를 보면서 재생 상태와 가사를 바로 확인할 수 있어서, 특히 폰으로 볼 때 유용합니다.

주의: 오디오 재생 중에는 무대 마커가 매 순간 자동으로 위치를 갱신하므로, 위치를 손으로 수정하려면 먼저 음원을 정지하세요. 등장/퇴장 상태도 음원 재생에 맞춰 자동 반영됩니다 — 어떤 역할이 A씬(큐)에서 퇴장 상태고 B씬(다음 큐)에서 등장 상태면, 재생이 B씬의 큐 시간에 도달하는 순간 무대에 나타납니다 (반대로 A에서 등장, B에서 퇴장이면 B의 큐 시간에 사라집니다).
파형은 브라우저가 오디오를 디코딩해서 그리는 참고용 그림이라 파일 형식에 따라 표시되지 않을 수 있지만(형식을 지원 안 하는 경우), 이 경우에도 탐색 막대·버튼·시간 입력 등 나머지 기능은 정상 동작합니다.

## 데이터 저장 / 배포

- 입력한 내용(역할·씬·음원 포함)은 브라우저의 로컬 저장소에 자동 저장됩니다 (같은 브라우저에서 다시 열면 이어서 편집 가능).
- **JSON 저장/불러오기**: 데이터를 백업하거나 다른 컴퓨터로 옮길 때 사용합니다. 음원 파일도 JSON 안에 함께 저장됩니다.
- **배포용 HTML로 내보내기**: 지금까지 입력한 동선·음원·가사가 그대로 담긴 새 `.html` 파일을 다운로드합니다. 이 파일 하나만 연출진/배우들에게 전달(카톡/메신저로 파일 전송, 구글드라이브 등)하면, 받은 사람은 아무 설치 없이 더블클릭만으로 음원 재생에 맞춘 동선까지 확인할 수 있습니다. 내보낸 파일은 지금 편집 모드가 켜져 있든 꺼져 있든 항상 "보기 모드"로 열리므로, 따로 신경 쓰지 않아도 받는 사람이 실수로 위치를 바꿀 일이 없습니다.
- 음원 파일이 크면(특히 수십 MB 이상) 내보낸 html 파일도 커집니다. 가능하면 필요한 구간만 자른 짧은 mp3나, 용량을 줄인 파일을 사용하는 걸 추천합니다.
- **아이폰에서 열었는데 화면은 뜨는데 아무 반응이 없다면**: 카카오톡 등 메신저 안에서 파일을 탭하면 iOS가 자바스크립트를 실행하지 않는 "미리보기(Quick Look)" 화면으로 먼저 엽니다. 그 화면에서 공유 버튼 → **"다른 앱으로 열기" → Safari**를 선택해야 실제로 동작합니다. 이 화면이 뜨면 파일 안에 빨간 안내 배너("이 화면은... 미리보기 화면이라...")가 자동으로 표시되도록 만들어 두었습니다.
- **파일 앱에 저장 후 Safari/Chrome으로 직접 열었는데도 반응이 없다면**: 렌더링이나 초기화 도중 실제 오류가 발생했을 가능성이 있습니다. 이 경우 화면 맨 위에 **보라색 오류 문구**가 자동으로 뜨도록 만들어 두었으니(예: `오류 발생 (renderAll): ...`), 그 문구를 스크린샷해서 알려주시면 정확한 원인을 찾을 수 있습니다. 이 안전장치 덕분에 특정 오류가 나더라도 나머지 버튼들은 계속 눌리도록 되어 있습니다.

## 모바일에서 보기

- 화면이 좁아지면(대략 폰 세로 화면 폭) 자동으로 모바일에 맞춘 레이아웃으로 바뀝니다: **무대 → 역할 목록**(내 배역 탭해서 강조하는, 보는 사람이 가장 많이 쓰는 기능) 순으로 위에 오고, **음원/가사 → 씬 목록**은 그 아래로 내려갑니다. 재생/가사는 무대 바로 아래 미니바로 항상 같이 보이니 따로 안 내려가도 됩니다.
- 버튼과 마커, 손잡이가 손가락으로 누르기 쉽게 커지고, 가사 줄의 ⏱/✕ 버튼도 (마우스 hover 없이) 항상 보이게 바뀝니다.
- 그래도 화면이 작다 보니 무대를 드래그로 세밀하게 편집하는 건 PC보다 불편할 수 있습니다 — 동선 편집은 PC에서, 배포 후 확인/따라가기는 폰에서 하는 걸 추천합니다.

## 참고

- 실제 무대 크기·비율과 다를 수 있는 개략적인 시각화입니다. 정확한 치수 도면이 아니라 "누가 대략 어디에 있고 어떻게 이동하는지" 감을 잡기 위한 용도입니다.
- 역할·씬 개수 제한은 없습니다 (2명~20명 이상, 씬도 자유롭게 추가). 역할이 아주 많아지면 무대가 복잡해 보일 수 있어 필요하면 역할 이름을 짧게(예: "기사1") 쓰는 걸 추천합니다.
- JSON 불러오기는 현재 편집 중인 내용을 덮어쓰므로 확인 창이 한 번 뜹니다. 실수로 덮어썼어도 바로 실행취소(Ctrl+Z)를 누르면 불러오기 직전 상태로 복구됩니다 (단, 그 사이에 다른 편집을 더 했다면 되돌리기 단계가 늘어날 수 있습니다).
- 최신 Chrome/Edge/Safari 기준으로 만들어졌습니다. 아주 오래된 브라우저에서는 일부 색상 표현이 다르게 보일 수 있습니다.
